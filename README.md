It is a 2020 to 2022 covid 19 death cases and affected people, country-wise analysis. Python is used for the entire data cleaning and visualization. In Python, Pandas is used for data cleaning, and NumPy is used for complex mathematical operations.

I faced some difficulties when I cleaned data because it showed the wrong output as I expected; it mostly happened in mathematical operations. Successfully get the right output after studying mistakes and corrections.

Performed data cleaning such as removing empty spaces and white spaces, replacing null values with mathematical operations, trimming white spaces, and saved cleaned data to the right file location.

The Matplotlib library was used here for visualization and implemented analytical thinking, found the right inputs for analysis, created charts such as bar charts, line charts, scatter plots, and more charts were used for meaningful insights.

Analysed most of the people's average COVID cases country-wise, and segregated year-wise affected people and how many beds and hospitals were used for that pandemic season, and what kinds of categories people were affected.

The top countries affected by COVID-19 and life expectancy distribution by country.
